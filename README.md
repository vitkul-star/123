# Duo Launcher

Маленький домашний экран для приставки Orange TV Box 4K (ZC4450V-ORM) с двумя плитками:

- **Orange TV** — стандартная оболочка (`com.orange.md.stb`)
- **AM Vision IPTV** (`com.amvision.iptv`)

Оболочка Orange не заменяется, а просто открывается как обычное приложение,
поэтому каналы и номера каналов остаются как есть.

## Как получить APK (без Android Studio)

1. Создай на github.com новый репозиторий (можно приватный).
2. Загрузи в него все файлы из этой папки (кнопка **Add file → Upload files**),
   включая скрытую папку `.github`. Если веб-загрузка скрытую папку не принимает,
   создай файл `.github/workflows/build.yml` вручную и вставь в него содержимое из архива.
3. Открой вкладку **Actions** → **Build APK** → дождись зелёной галочки (3–5 минут).
4. Открой выполненный запуск, внизу в разделе **Artifacts** скачай `duo-launcher-apk`
   и распакуй zip: внутри `app-debug.apk`.

## Как установить на приставку

Через ATV Tools (отправка APK) или по ADB:

```
adb install app-debug.apk
```

## Как сделать домашним экраном

1. Нажми кнопку **Home** на пульте. Система может предложить выбрать лаунчер:
   выбери **Duo Launcher** и «Всегда».
2. Если вопрос не появился, открой через ADB:

```
am start -n com.duo.launcher/.MainActivity
```

   и нажми Home ещё раз.

Если прошивка Orange не даёт сменить домашний экран, лаунчер всё равно можно
открывать из списка приложений.

## Как вернуть всё как было

Удали приложение: `pm uninstall com.duo.launcher` — домашний экран вернётся прежним.
